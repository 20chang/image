# main — 清楚展示商品及本次售卖内容

> 状态：**完整实现**

## 目标

产出一张能看清商品全貌、适用于商品主图 / 首图的图：轮廓完整、主体突出、无干扰元素，买家一眼认出卖的是什么。

## 必要输入

| 输入 | 必要性 | 说明 |
|------|--------|------|
| 商品名称与事实 | 必要 | 决定外观主张与文案边界 |
| `primary` 参考图 | 必要 | 同款整体图，决定主体外观 |
| 制图要求 `drawingRequest` | 必要 | 用户对主图的具体要求 |
| `detail` / `composition` / `style` 参考 | 可选 | 补充细节、构图、风格 |

缺少 `primary` 时不得生成 — 应列出待确认问题。

## 设计选择

1. **构图**：白底或极简背景；主体居中偏满幅；正面偏 45° 能同时看到正面与侧面厚度；完整轮廓不出画、不裁切。
2. **光影**：柔光防过曝；高光不死白、暗部有细节；商品边缘清晰可辨。
3. **视角**：以买家理解商品结构为准 — 不用夸张透视、不用艺术化仰俯角。
4. **售卖内容**：若本次售卖含附件（支架、线束、说明书等），需在主图或后续图中可见；事实不足则列入待确认。

## 约束

- 不得引入参考图中「忽略」范围内的元素（背景、文字、Logo、其他商品）
- `other_product` / `no_product` 的图只可参考构图 / 风格，不得提供主体外观
- `aiStatus=yes` 的图，结构细节可能失真；关键结构以 `same_product` + `aiStatus=no` 为准
- 不编造事实（如 IP 等级、光效参数）；无依据的卖点不进提示词
- 保留用户 `drawingRequest` 中的明确要求；与本规则冲突时列入待确认

## 检查标准

- [ ] 商品轮廓完整、主体占比合适
- [ ] 白底 / 干净背景，无多余文字与 Logo
- [ ] 光影均匀，无过曝死白
- [ ] A/B/C 使用与忽略范围均已体现在提示词
- [ ] 事实不足处已列入「待确认问题」，未编造
